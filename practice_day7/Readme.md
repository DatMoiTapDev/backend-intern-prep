# Practice Day 7: Mini Project - Server Monitoring System

## 🎯 Mục tiêu
Tổng hợp toàn bộ kiến thức Python Core (Biến, Kiểu dữ liệu, Vòng lặp, Câu điều kiện, Hàm, OOP, Xử lý File, Xử lý lỗi, Datetime, Type Hinting) vào một hệ thống thống nhất có tính ứng dụng thực tế.

## 📝 Yêu cầu Dự án
Xây dựng một hệ thống giám sát bằng OOP (`class Server` và `class SystemMonitor`) có khả năng:
1. Thêm máy chủ vào hệ thống quản lý.
2. Cập nhật trạng thái tự động (mô phỏng).
3. Quét hệ thống, phát hiện các máy chủ `offline` hoặc RAM quá thấp.
4. Ghi log các sự cố (kèm thời gian thực) ra một file `system_logs.txt`.
5. Đảm bảo chương trình không bị văng lỗi (crash) khi dữ liệu đầu vào bị sai.
