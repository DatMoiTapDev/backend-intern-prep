# Practice Day 4: File I/O, Datetime và Code Tối Ưu

## 🎯 Mục tiêu
Nắm vững cách chương trình tương tác với hệ điều hành (Đọc/Ghi file lưu cấu hình, ghi log), xử lý thời gian thực, và làm quen với cách viết code Pythonic gọn gàng (List Comprehension).

## 📝 Đề bài
**Bài 1: Viết code siêu ngắn (List Comprehension)**
Rút gọn vòng lặp `for` và `if` thành 1 dòng duy nhất để lọc danh sách IP.

**Bài 2: Ghi Log hệ thống (File I/O)**
Viết hàm mở một file `server_logs.txt` ở chế độ ghi tiếp (append). Ghi một dòng cảnh báo lỗi vào file đó.

**Bài 3: Xử lý Thời gian thực (Datetime)**
Sử dụng thư viện `datetime` có sẵn của Python để lấy giờ hệ thống hiện tại, sau đó nối với chuỗi thông báo khởi động Server.

**Bài 4: Hàm có tham số mặc định (Default Parameters)**
Viết hàm tạo User, trong đó nếu không truyền vai trò (role) thì hệ thống tự động gán là "user" thường. 

**Bài 5: OOP kết hợp File I/O (Lưu cấu hình Database)**
Tạo `class DatabaseConfig`. Viết phương thức cho phép đối tượng tự động tạo ra một file `config.txt` và ghi các thông số (host, port, user) của nó vào file hệ thống.
