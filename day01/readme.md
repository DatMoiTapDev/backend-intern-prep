# Day 1: Cơ bản về Biến, List và Dictionary trong Python

## 🎯 Mục tiêu
Làm quen với cách lưu trữ và truy xuất dữ liệu cơ bản trong lập trình Backend bằng `Dictionary`.

## 📝 Đề bài
Vận dụng kiến thức về **Dictionary**, thực hiện các yêu cầu sau:
1. Tạo một biến tên là `my_server`.
2. Gán cho nó một Dictionary chứa 3 thông tin của máy chủ sau:
   - `hostname`: "ubuntu-server-01"
   - `os`: "Linux"
   - `ram_gb`: 16 
3. Dùng lệnh `print()` để in ra màn hình **chỉ riêng hệ điều hành (`os`)** của máy chủ đó.
